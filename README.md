## 📝 How to use the interface

The dashboard shows all available settings for your a3modz menu. You can change these settings by clicking the buttons and switches on the screen. 

* Organizing Options: Use the tab menu to group your settings into categories. This helps you find specific scripts faster during use.
* Saving Changes: Click the Apply button after you adjust a setting. The utility writes these changes to the internal configuration files to ensure your menu reflects the new behavior.
* Refreshing the Menu: If you update your scripts, click the Refresh icon. This reloads the current data for your menu and brings in any new options you added.

## 🛡️ Troubleshooting common issues

If you face problems, check the items below:

* Browser Security: Some browsers block scripts from accessing local files. If the menu does not load, ensure you allowed the browser to read local files or use a dedicated local web server tool.
* File Paths: Keep all files in the same folder. If you move the index file away from its supporting scripts, the menu will not find its icons or configuration data.
* Missing Changes: Always click the Save or Apply button before you close your browser. The tool loses unsaved changes if you close the tab early.

## 📁 File structure

Knowing the files helps if you ever need to back up your setup:

* index.html: This is the main file that builds the visual interface.
* assets/: This folder contains images, icons, and styling files.
* config/: This folder stores your personal settings. Back up this folder regularly to keep your custom menu behavior safe.
